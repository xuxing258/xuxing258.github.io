爬虫逆向

很多网站会做出反爬技术, 爬虫逆向则是针对这些技术做出反反爬虫手段

  • 市场监管平台: https://jzsc.mohurd.gov.cn/since/fake 解密
  • 区块链交易列表: https://www.oklink.com/zh-hans/bitcoin/tx-list 加密

作用: 通过分析网站或App的反爬虫机制，破解其数据加密、接口验证等技术手段，从而绕过限制获取目标数据的过程。

  • 怎么加密的: 基本上都是对某些参数进行加密 => 通过js代码计算的
  • 逆向是对加密数据进行加密逻辑分析, 分析出正确加密方法
    • 通过加密方式进行解密,
    • 通过加密方式设置请求头或参数等等,进行发起请求,从而通过验证,获取数据

加盐校验(哈希函数)

  • 一种单向加密函数，将任意长度的数据转换成固定长度的字符串。相同输入永远产生相同输出
  • 通常用在密码存储和验证过程中使用

比如: md5 sha1 sha256 加密后无法还原 => 称为哈希函数

md5

md5无法解密, 存在16位, 32位, 40位 (生成的是十六进制)

  • "字符串".encode("utf-8")
    • 将字符串按照 UTF-8 编码规则转换为二进制数据
  • "二进制".decode('utf-8')
    • 将二进制转换成UTF-8 编码字符串
  • hexdigest(): 输出32位十六进制哈希值
  • digest: 输出bytes原始字节形式的哈希(二进制)
# 通过123456进行加密来判断是否为md5加密
# 加密值为 e10adc3949ba59abbe56e057f20f883e
from hashlib import md5

# 创建MD5哈希对象
data = md5("123456".encode("utf-8"))  
print(data)
# 十六进制
print(data.hexdigest())     
# e10adc3949ba59abbe56e057f20f883e
print(data.digest()) #b'\xe1\n\xdc9I\xbaY\xab\xbeV\xe0W\xf2\x0f\x88>'

# 注意: 十六位数是从32位MD5结果中截取一部分  40位是进行填充

sha

sha1,sha224, sha256

通常会以十六进制 或 Base64 的形式表示; 一般为十六进制

from hashlib import sha1, sha224, sha256
# sha1是40位  SHA224输出56位 sha256输64位
data = sha224("123456".encode("utf-8"))
print(data.hexdigest())  # 十六进制
# f8cdb04495ded47615258f9dc6a3f4707fd2405434fefc3cbf4ef4e6
print(data.digest())  # 原始二进制

base64

Base64 是一种将二进制数据(字节)编码为 ASCII 字符串的编码方式

  • base64.b64encode: 用于将二进制数据进行 Base64 编码。
from hashlib import sha1, sha224, sha256, md5
import base64
# 将二进制转换转码
data = sha224("123456".encode("utf-8"))
print(base64.b64encode(data.digest()).decode('utf-8'))
  • base64组成 A-Z a-z 0-9 - = / 组成
  • base64数据 后面一般是= 或 == 结尾

注意:

  • 对原始字符串进行哈希处理(digest()),然后进行Base64编码,数据不可逆
  • 不能还原成原本真正的数据, 但是可以还原md5 sha哈希函数加密后值
未执行哈希,可还原
import base64
# 原始字节数据
data = "Hello World".encode('utf-8')
# Base64 编码
encoded = base64.b64encode(data).decode('utf-8') 
# 输出: "SGVsbG8gV29ybGQ="

# 将以上的数据进行还原
result = base64.b64decode(encoded).decode('utf-8')
print(result)  # Hello World
浏览器Base64

btoa函数可将ASCII或UTF-8字符串 => 编码为Base64格式

btoa不能直接处理 中文和表情, 如果字符串包含非 ASCII 字符（如 中文或 😊），需要先进行 UTF-8 编码

btoa("123456")  // 输出 'MTIzNDU2'

atob()用于将 Base64 编码的字符串 解码回原始的二进制数据

atob('MTIzNDU2') // "123456"

crypto-js

是一个JavaScript加密库，它提供了各种加密算法，包括MD5、SHA-1、SHA-256、AES、DES等, 在JavaScript环境中使用

// node中使用
const crypto = require("crypto-js")
function handlermd5(val) {
    let hash = crypto.MD5(val).toString()
    return hash
}
handlermd5("123456")

对称与非对称加密

非对称加密

最经典和广泛使用的非对称加密算法。

使用一对密钥：一个公钥和一个私钥

  1. 公钥：公开的，用于加密（锁信箱）或验证签名。
  2. 私钥：绝对私有的，用于解密（开信箱）或创建签名。

对称加密

加密和解密使用同一把密钥

对称加密

AES

AES 是一种对称分组密码，是当今全球使用最广泛、最安全的加密算法之一, 通常会以 十六进制（Hex） 或 Base64 的形式表示

可变密钥长度：AES 支持三种不同的密钥长度，这直接决定了其安全强度：

  • AES-128：密钥长度 = 128 位 → 进行 10 轮处理
  • AES-192：密钥长度 = 192 位 → 进行 12 轮处理
  • AES-256：密钥长度 = 256 位 → 进行 14 轮处理
区分

如果没有混淆时会出现AES对象, 则可判断位AES进行加密与解密

AES.encrypt() 加密的参数会根据编程语言和加密库的不同而有所差异

  • msg: 加密数据

  • key （密钥）：bytes 类型，长度必须为 16（AES-128）、24（AES-192）或 32（AES-256）字节

  • 配置对象

    • mode（加密模式）：AES.MODE_* 类型，如 AES.MODE_CBC、AES.MODE_GCM、AES.MODE_ECB（不推荐）
    • iv bytes 类型，视模式而定，CBC/GCM 等模式需要 16 字节，ECB 不需要
    • padding: bytes 类型，需先填充为 16 字节的倍数（如用 PKCS7 填充）

AES.decrypt: 解密

  • data 待解密的密文

  • key bytes是必须与加密时使用的密钥相同（16/24/32 字节）。

  • 配置对象

    • mode 需与加密模式一致
    • iv : 视模式而定 必须使用加密时的 IV
    • padding: 需与加密填充方式一致
// 在node.js
const CryptoJS = require('crypto-js');
// 1. 简单的 AES 加密和解密
const msg = 'Hello, World!';
const key = 'mySecretKey123456'; // 密钥，可以是任意字符串
// 加密
const encrypted = CryptoJS.AES.encrypt(msg, key);
console.log('加密结果:', encrypted.toString());
// 解密
const decrypted = CryptoJS.AES.decrypt(encrypted,key);
console.log(decrypted.toString(CryptoJS.enc.Utf8));

const plaintext = CryptoJS.AES.decrypt(
  ciphertext, 
  key, 
  { iv, mode, padding }
).toString(CryptoJS.enc.Utf8);

DES

通常会以 十六进制（Hex） 或 Base64 的形式表示

DES密钥在形式上是一个 64位（8字节） 的字符串。然而，在这64位中，每第8位（即第8、16、24、32、40、48、56、64位）被用作奇偶校验位，不参与实际的加密运算。因此，真正起作用的、用于加密的密钥只有 56位（7字节)

加密DES.encrypt() 解密 DES.decrypt

  • 明文 (message)： 要加密的是什么？通常是用户名、密码、时间戳或其他请求参数的组合。
  • 密钥 (key)： 密钥是什么？它可能是固定的（写死在JS里），也可能是动态生成的（需要其他JS函数计算）。
  • 加密模式 (mode)： 如 ECB, CBC 等。
  • 填充方式 (pad)： 如 Pkcs7, ZeroPadding 等。

非对称加密

RSA ECC DSA

(私钥 公钥): 同一个明文可以生成不同的密文, 通常会以 十六进制（Hex） 或 Base64 的形式表示

  • 如果是通过公钥加密, 则需通过私钥进行解密
    • 加密（用于保证数据的机密性）
      • 你想"隐藏"数据（用公钥加密，私钥解密）
  • 如果是通过私钥加密, 则需通过公钥进行解密
    • 签名（用于保证数据的真实性和完整性）
      • 你想"证明"身份（用私钥加密，公钥解密）
        • 因为公钥是公开的，任何人只要解开就能看到数据，所以没有保密性

通常有以下函数名：

  1. 密钥生成：generateKeyPair, generateKeys, keyGen
  2. 加密：encrypt, rsaEncrypt
  3. 解密：decrypt, rsaDecrypt
