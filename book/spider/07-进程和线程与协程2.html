协程概述

协程（Coroutine） 是一种轻量级的并发编程模型，可以在单个线程内实现并发, 协程之间通过yield或await进行切换，而不是线程切换，因此开销更小。

  • 单线程内运行：所有协程共享同一个线程，由事件循环（Event Loop）调度
  • 非阻塞异步：遇到 I/O 操作时主动让出控制权，不阻塞线程。
    • 遇到await 网络请求会主动让出
    • 遇到await asyncio.seep(10) 等待会主动让出
  • 低开销：协程切换在用户状态完成，无需操作系统介入。

进程和线程都是受操作系统管理, 协程是受用户管理

协程基础

pip install asyncio 通过 asyncio库原生支持协程

  • 使用async def定义异步函数(协程函数)
  • 调用协程函数时，不会立即执行，而是返回一个协程对象
  • 协程必须在事件循环（Event Loop） 中运行，由事件循环调度执行。
import asyncio
# 通过async定义一个协程函数（异步函数）
async def main_xie(url):
    print('请求：',url)
  
# 直接调用
main_xie("https://www.baidu.com") # 报错

# 调用获取协程对象c
c = main_xie("https://www.baidu.com")
print(c,"携程对象")  
# <coroutine object main_xie at 0x00000270417B36B0>

并发

await

  • 挂起当前协程：当执行到 await 时，当前协程会暂停执行，主动让出控制权给事件循环,事件循环会调度其他就绪的协程（或任务）运行，从而实现并发
    • await asyncio.sleep(2)
    • await 异步请求
  • 等待可等待对象完成：await 会等待后面的对象（协程、Future、Task 等）执行完毕，并返回其结果。
    • 当被等待的对象完成后，事件循环会恢复当前协程，继续执行 await 之后的代码
  • 在另一个协程中调用协程：必须使用 await coroutine()，否则协程不会执行（只会得到一个未运行的协程对象）。

crate_task并发

  • asyncio.gather 同时启动所有协程，并发执行
    • 返回值顺序：结果顺序与输入顺序一致
import asyncio
import time
# 记录当前时间
s = time.time()

async def task1():
    print("Task1 开始")
    # 这行代码会让出控制权2秒钟
    await asyncio.sleep(2)  # 比如网络请求
    print("Task1 完成")
    return 456

async def task2():
    print("Task2 开始")
    # 这行代码会让出控制权1秒钟
    await asyncio.sleep(1)  
    print("Task2 完成")
    return 456
	
# asyncio运行异步函数入口函数
async def main():
    # 将协程包装任务,在后台并发执行
    f1 = asyncio.create_task(task1())
    f2 = asyncio.create_task(task2())
    # 同时启动所有协程，并发执行 可以获取返回值
    aa = await asyncio.gather(f1, f2)
    # await 等待所有协程执行完成 获取返回值,
    # 不使用await无法获取返回值
    print(aa)
    pass
    
if __name__ == '__main__':
    asyncio.run(main())
    print("耗时", time.time()-s)

future并发

使用ensure_future原因是: 需要兼容旧版本或处理未知类型的可等待对象，否则优先使用 asyncio.create_task()

  • ensure_future 创建协程任务对象
  • asyncio.wait([f1, f2]) 同时启动所有协程，并发执行
import asyncio
import time
# 记录当前时间
s = time.time()

async def task1():
    print("Task1 开始")
    await asyncio.sleep(4)  # 暂停2秒
    print("Task1 完成")

async def task2():
    print("Task2 开始")
    await asyncio.sleep(4)  # 暂停1秒
    print("Task2 完成")


async def main():
    # ensure_future 创建协程任务对象
    f1 = asyncio.ensure_future(task1())
    f2 = asyncio.ensure_future(task2())
    # 并发执行多个协程任务对象
    await asyncio.wait([f1, f2])

if __name__ == '__main__':
    asyncio.run(main())
    print("耗时", time.time()-s)
