WSL2

WSL2 就像给 Windows 电脑装了一个“超强兼容模式”。你现在不需要重启，也不需要打开一个笨重的虚拟机窗口。你只需要打开一个命令行终端（比如 Windows Terminal），在里面输入 wsl，就能瞬间进入一个轻量级的 Linux 环境。你的 Windows 文件和 Linux 文件可以互相访问，Linux 程序可以直接运行，甚至可以直接在 Windows 桌面上打开 Linux 程序的图形界面窗口

使用前提

  1. 开启电脑CPU虚拟化=>任务管理器=>性能=>右下方查看虚拟化(默认启动)
  2. 在搜索框中输入: 启动或关闭window功能
    • 在选项中勾选上: 适用于Linux的window子系统
  3. 使用wsl2

下载WSL2

cmd管理员运行: wsl --install 进行安装wsl2

重新启动电脑

确保WSL2是默认版本: wsl --set-default-version 2

指令

  • wsl --uninstall 卸载 WSL 程序本身

安装其他Linux版本

执行wsl --list --online 获取可安装的操作系统

  • wsl --list --online 展示可以安装的Linux版本
  • wsl --list -v 展示电脑安装过的Linux版本
  • wsl --unregister linux名称 删除对应的liunx版本(清空内容)
    • Ubuntu-22.04
  • wsl --shutdown 重启linux

Ubuntu

  • wsl --install -d Linux名称 wsl --install -d Ubuntu-22.04

wsl使用

在cmd中或powerShell中输入 wsl 就可以进行启动

安装openClaw

终端中输入: curl -fsSL https://openclaw.ai/install.sh | bash

安装成功之后: 会出现对应的logo

选项

  1. 说明使用的风险, 选择YES
  2. Onboarding mode: 选择模式
    • 选择快速开始模式 QuickStart
    • 手动模式 Manual
  3. 进行大模型配置
    • 选择Skip fow now跳过: 后续在添加, 先运行成功
  4. 供应商模型界面
    • 保持默认
  5. 模型选择界面
    • 保持默认
  6. Select channel 选择频道界面(聊天频道)
    • 选择Skip fow now跳过

使用

  • openclaw --version 查看安装版本
  • which openclaw 查看安装位置
  • openclaw dashboard 打开浏览器 UI
  • openclaw doctor 检查配置问题
  • openclaw status Gateway 网关状态

查看网关令牌

  • openclaw dashboard
    • 执行时就会存在网管指令: 赋值存在token的数据即可
  • openclaw dashboard --no-open
    • 获取浏览器地址与网管令牌
  • openclaw gateway stop
    • 停止运行小龙虾
  • openclaw gateway --allow-unconfigured
  • 启动小龙虾: 获取日志信息

openclaw.json文件配置

  • nano ~/.openclaw/openclaw.json 进行编辑openclaw.json文件

    • Ctrl+O 保存
      • Enter 确认
    • Ctrl+X 退出

  • openclaw gateway restart

  • 重启openclaw.json服务

deepseek配置

  1. 环境变量

    • export DEEPSEEK_API_KEY="deepseek的key"

  2. 在配置文件中注册 DeepSeek 提供商

openclaw config set models.providers.deepseek '{
  "baseUrl": "https://api.deepseek.com/v1",
  "apiKey": "'"$DEEPSEEK_API_KEY"'",
  "api": "openai-completions",
  "models": [
    { "id": "deepseek-chat", "name": "DeepSeek Chat (V3)" },
    { "id": "deepseek-reasoner", "name": "DeepSeek Reasoner (R1)" }
  ]
}'
  1. 指定默认模型

修改配置文件 ~/.openclaw/openclaw.json

# openclaw.json文件配置
"agents": {
  "defaults": {
    "model": "deepseek/deepseek-chat"
  }
}

  1. openclaw gateway restart

    • 更新openclaw.json服务,
