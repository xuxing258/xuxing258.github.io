selenium介绍

Selenium 是一个强大的浏览器自动化工具, 广泛用于网页测试和爬取动态加载内容, (主要是用于自动化测试)

自动化是指使用技术手段模拟人工，执行重复性任务,

安装 pip install selenium

官网: https://www.selenium.dev/zh-cn/documentation/webdriver/browsers/chrome/

浏览器的启动

webdriver.Chrome() webdriver.Edge() webdriver.Firefox() webdriver.Safari()

# 引入webdriver驱动,启动浏览器
from selenium import webdriver 
# 启动浏览器 需要打开对应窗口
driver = webdriver.Chrome()     	# 可以设置其他浏览器
# 打开网页  打开后浏览器会自动关闭
driver.get("https://www.baidu.com")
# 可以设置input()输入内容 停止浏览器关闭
input("请输入内容") # 输入内容之后,会自动关闭
  • driver.page_source 获取网页源代码
  • driver.close() 关闭页面
  • driver.quit() 退出浏览器
  • driver.title 获取网页的title标签信息
  • driver.current_url 获取当前网页的url

浏览器配置信息

options = webdriver.ChromeOptions() 
# 两种使用方式功能一致
from selenium.webdriver.chrome.options import Options
options = Options()
# edge浏览器: webdriver.EdgeOptions()
  • ("detach", True) 保持浏览器的打开状态
  • ('excludeSwitches', ['enable-automation'])
    • 隐藏浏览器的自动化痕迹，避免被网站检测到是自动化程序在操作
    • 移除自动化控制特征(避免被网站检测到是自动化程序在操作)
    • options.add_argument("--disable-blink-features=AutomationControlled")
      • 将自动化修改成false, 避免被检测到
  • --start-maximized 最大化窗口
  • --no-sandbox 禁用沙盒模式-解决Linux权限不足导致崩溃问题
    • 现在基本不需要设置
from selenium import webdriver 
# 设置浏览器配置信息  
options = webdriver.ChromeOptions() 
# 保持浏览器的打开状态
options.add_experimental_option("detach", True)
# 隐藏自动化提示栏,
options.add_experimental_option('excludeSwitches', ['enable-automation'])
# 最大化窗口
options.add_argument("--start-maximized") 
# 沙盒模式  基本不需要设置
options.add_argument("--no-sandbox")     
# 传入配置信息
driver = webdriver.Chrome(options=options)

# 获取网页的源码
print(driver.page_source)
print(driver.title)

获取元素

百度首页演示: https://www.baidu.com/index.htm

  • 浏览器对象.find_element(By.type, "value")
    • type: 选择对应方式定位元素
      • 示例: By.ID 或 By.CLASS_NAME
    • value: 是type方式对应的类名或id名等等
  • 元素节点.get_attribute("outerHTML") 获取元素整体内容
  • 元素节点.text 获取元素文本内容

循环滚动

last_height = driver.execute_script("return document.body.scrollHeight")
while True:
    # 滚到底部
    driver.execute_script("window.scrollTo(0, document.body.scrollHeight);")
    time.sleep(2)  # 等待新数据加载
    
    new_height = driver.execute_script("return document.body.scrollHeight")
    if new_height == last_height:  # 高度不再增加，说明到底了
        break
    last_height = new_height

等待

WebDriverWait用于设置等待网页元素加载或获取时长

from selenium import webdriver
from selenium.webdriver.common.by import By 
# 设置等待网页元素加载或获取时长
from selenium.webdriver.support.wait import WebDriverWait 
#与WebDriverWait配合使用，实现等待页面元素的各种状态
from selenium.webdriver.support import expected_conditions as EC

browser = webdriver.Chrome()
browser.get('https://www.taobao.com/')

# 创建等待对象，设置最长等待时间为 10秒
wait = WebDriverWait(browser,  timeout=10)
#使用wait查询会等待元素加载成功,最长等待10秒, 超过时间未获取则报错
input = wait.until(EC.presence_of_element_located((By.ID,'J_SiteFooter')))
print("123123")

补充: 在等待的过程中,后续的程序不会执行

wait没有查询到结果或未超时 print("123123")不会执行

等待条件: 在文档的额外功能, 期望状态位置

# 创建等待对象，设置最长等待时间为 10秒
wait = WebDriverWait(driver, timeout=10)

# 等待元素在DOM中存在且可见（宽度/高度>0，非隐藏）
visible_element = wait.until(EC.visibility_of_element_located((By.XPATH, "//div")))

# 检查元素是否出现在DOM中
hidden_element = wait.until(EC.presence_of_element_located((By.CLASS_NAME, "item")))

# 等待元素可见且可点击（Enabled状态） 用于:提交按钮、超链接等
login_button = wait.until(EC.element_to_be_clickable((By.LINK_TEXT, "登录")))

# 验证文本内容
success_msg = wait.until(EC.text_to_be_present_in_element((By.ID, "status"), "成功"))

# 等待元素不可见或从DOM中移除（常用于等待加载动画消失）
wait.until(EC.invisibility_of_element_located((By.ID, "loading")))

浏览器配置

有效降低被网站检测为自动化的风险，适用于爬虫和自动化测试场景

配置内容: https://peter.sh/experiments/chromium-command-line-switches/ 位于浏览器 => 选择任意浏览器 => 参数的list of C...位置

参数作用典型应用场景
--start-maximized启动时最大化窗口避免元素因窗口太小导致不可见
--headless=new无头模式（不显示GUI界面）服务器环境或不需要可视化时节省资源
--user-data-dir=/path/to/profile加载指定用户数据目录（保存Cookies/扩展/历史记录）复用登录状态或自定义浏览器环境
--incognito隐身模式（不读取历史记录，新建临时会话）确保每次启动都是干净环境
--disable-gpu禁用GPU加速（旧版无头模式可能需要）解决无头模式下的兼容性问题
--window-size=1200,800设置初始窗口大小（宽×高）需要固定窗口尺寸时使用
--disable-extensions禁用所有扩展避免扩展干扰自动化操作
--no-sandbox禁用沙盒模式（Linux服务器可能需要）解决Linux权限不足导致崩溃问题
--disable-blink-features=AutomationControlled修改 navigator.webdriver返回值
from selenium.webdriver.chrome.options import Options
options = Options()
options.add_argument("--start-maximized")       # 最大化窗口
options.add_argument("--headless=new")          # 无头模式  不显示浏览器

# 存储用户数据目录 (保存cookies、缓存等)  使其访问时, 能保持登录状态
options.add_argument("user-data-dir=D:/授课/1-15肥虫班/Day8/jd/data") # 必须为绝对路径，且目录需已存在

driver = webdriver.Chrome(options)
driver.get('https://www.baidu.com')

def handler_html(driver):
    # 控制页面滚动到最下方 加载内容
    js = "window.scrollTo(0,document.documentElement.scrollHeight)"
    driver.execute_script(js)
    time.sleep(2)
    # 提取数据
    html = driver.page_source
    xml = etree.HTML(html)
    hrefs = xml.xpath('//div[@id="content_items_wrapper"]/div/a/@href')[:2]
    for href in hrefs:
        if not href.startswith('http'):
            href = 'https:' + href
        # 记录当前标签页对象id
        cur_index = driver.current_window_handle
        # 获取详情页面数据  通过js调用  下一期不要使用该方法
        # open_js = f"window.open('{href}','_blank')"
        # driver.execute_script(open_js)

        # 通过selenium原生使用
        driver.switch_to.new_window("tab")
        driver.get(href)
        tab_id = driver.current_window_handle
        time.sleep(2)
        driver.switch_to.window(tab_id)
        title, price, shop_name = handelr_message(driver)
        print(title, price, shop_name)
        print("==============================")
        driver.close()
        driver.switch_to.window(cur_index)
        time.sleep(2)
    # 翻页
    try:
        wait = WebDriverWait(driver, timeout=10)
        next_but = wait.until(EC.presence_of_element_located(
            (By.XPATH, '//*[@id="search-content-leftWrap"]/div[2]/div[5]/div/div/button[2]')))
        # 判断是否存在disabled属性
        if not next_but.get_attribute("disabled"):
            driver.execute_script("arguments[0].click();", next_but)
            handler_html(driver)
        else:
            print("程序结束", driver.current_url)
    except ElementClickInterceptedException as e:
        print(e)
    pass

案例注意

  • 可以使用css选择器方式获取
    • browser.find_element(By.CSS_SELECTOR, '#chat-input-area #chat-textarea')
  • 判断是否存在disabled属性
    • 不存在disabled属性返回值是None
  • 触发点击时,如果点击元素是在不可见区域会报错
    • driver.execute_script("arguments[0].click();", next_but)
    • 把 next_but 这个按钮对象交给浏览器，让浏览器直接用原生的 JavaScript 去触发它的点击事件

https://bot.sannysoft.com/

这个网站就像一个“照妖镜”，能清晰地照出你的Selenium浏览器和真实浏览器的所有不同。它上面红色（Failed）的项目越多，说明你的浏览器指纹越假，越容易被目标网站检测到。

使用代码请求这个网站时

  • 绿色（Pass）：表示该项特征与正常浏览器一致，暂时安全。
  • 红色（Failed）：表示该项特征暴露了你正在使用自动化工具，是风险点

总之，红色的项目就是你需要逐个去“修复”的指纹。

操作

  1. 先用你正常的浏览器（比如 Chrome）打开这个网站，截图记录下正常状态（大部分是绿色标识）。
  2. 再用你被百度检测的Selenium脚本打开这个网站。
