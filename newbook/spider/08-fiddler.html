Fiddler Classic（永久免费) 只支持window, mac或Liunx需要付费

Fiddler的简介

Fiddler是位于客户端和服务器端之间的代理，也是目前最常用的抓包工具之一 。它能够记录客户端和服务器之间的所有 请求，可以针对特定的请求，分析请求数据、设置断点、调试web应用、修改请求的数据，甚至可以修改服务器返回的数据，功能非常强大，是web调试的利器。 看到这么多的应用，是不是就迫不及待的想要开始你的抓包之旅呢，不要急，俗话说的好：工欲善其事，必先利其器，我们先来安装Fiddler吧。

安装

若你只需基本抓包、查看流量且仅在 Windows 上使用，可继续选择 Fiddler Classic（永久免费）。

若你使用 Linux/macOS，或需要现代协议支持（HTTP/2、gRPC 等）、团队协作、规则引擎等功能，可用 Fiddler Everywhere，但需订阅（有免费试用机会）。

Fiddler Classic 是一款 Windows 平台下的 免费 HTTP 调试代理工具，由 Telerik（现为 Progress 公司）开发，广泛用于 Web 开发、接口调试、抓包分析、性能优化等场景。(在window的旁边既可以下载mac)

官网下载地址: https://www.telerik.com/download/fiddler

点击close关闭即可完成安装

请求 (Request) 部分详解

  • Headers: 显示客户端发送到服务器的 HTTP 请求的 header，显示为一个分级视图，包含了 Web 客户端信息、Cookie、传输状态等。

  • Textview和语法查看

    • 显示 POST 请求的 body 部分为文本。

  • WebForms:

    • 显示请求的 GET 参数

  • HexView 用十六进制数据显示请求。

  • Auth

    • 显示响应 header 中的 Proxy-Authorization(代理身份验证) 和 Authorization(授权) 信息.

  • Raw : 将整个请求显示为纯文本。

  • JSON - 显示JSON格式文件。

  • XML

    • 如果请求的 body 是 XML 格式，就是用分级的 XML 树来显示它。

响应 (Response) 部分详解

  1. Transformer —— 显示响应的编码信息。
  2. Headers —— 用分级视图显示响应的 header。
  3. TextView —— 使用文本显示相应的 body。
  4. SyntaxView——响应数据
  5. ImageVies —— 如果请求是图片资源，显示响应的图片。
  6. HexView —— 用十六进制数据显示响应。
  7. WebView —— 响应在 Web 浏览器中的预览效果。
  8. Auth —— 显示响应 header 中的 Proxy-Authorization(代理身份验证) 和 Authorization(授权) 信息。
  9. Caching —— 显示此请求的缓存信息。
  10. Privacy —— 显示此请求的私密 (P3P) 信息。
  11. Raw —— 将整个响应显示为纯文本。
  12. JSON - 显示JSON格式文件。
  13. XML —— 如果响应的 body 是 XML 格式，就是用分级的 XML 树来显示它 。

注意

网站地址栏展示不安全

第一步:

  1. 先暂时关闭 Fiddler 的 HTTPS 解密，让浏览器恢复正常：
  2. 打开 Fiddler，点击菜单 Tools -> Options -> 切换到 HTTPS 选项卡。
  3. 取消勾选 Decrypt HTTPS traffic（解密 HTTPS 流量）。
  4. 重启 Chrome 浏览器，此时访问 www.baidu.com 应该立刻恢复正常。

第二步: 重置并正确安装 Fiddler 证书

  1. 重置旧证书：在 Fiddler 的 HTTPS 选项卡中，点击右侧的 Actions 按钮，选择 Reset All Certificates（重置所有证书），弹出的提示全部点“是/确定”。
  2. 导出新证书：重置完成后，再次点击 Actions 即可完成, 如不成请看以下操作
  1. 导出新证书：重置完成后，再次点击 Actions -> Export Root Certificate to Desktop（导出根证书到桌面），此时桌面会生成一个 FiddlerRoot.cer 文件。
  2. 关键一步（安装到本地计算机）：
    • 双击桌面的 FiddlerRoot.cer 文件，点击 “安装证书”。
    • 在安装向导中，“存储位置” 必须选择 “本地计算机”（Local Machine），然后点“下一步”。
    • 选择 “将所有证书放入下列存储”，点击右侧的 “浏览”，在弹出的列表中选择 “受信任的根证书颁发机构”（Trusted Root Certification Authorities）。
    • 一路点击“下一步”和“完成”，直到提示导入成功。

# 主要讲解的是fiddler 
import re
import requests
import json

def spider(url):
    headers = {
        "accept": "*/*",
        "accept-language": "zh-CN,zh;q=0.9",
        "cache-control": "no-cache",
        "pragma": "no-cache",
        "referer": "https://news.163.com/",
        "sec-ch-ua": "\"Google Chrome\";v=\"143\", \"Chromium\";v=\"143\", \"Not A(Brand\";v=\"24\"",
        "sec-ch-ua-mobile": "?0",
        "sec-ch-ua-platform": "\"Windows\"",
        "sec-fetch-dest": "script",
        "sec-fetch-mode": "no-cors",
        "sec-fetch-site": "same-origin",
        "user-agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/143.0.0.0 Safari/537.36"
    }
    params = {
        "callback": "data_callback"
    }
    response = requests.get(url, headers=headers, params=params)
    if response.status_code == 200:
        return response.text
    else:
        return None
    pass

def handler_jsonp(data):
    # 正则进行匹配获取数据
    value = re.match(r'data_callback\((.*)\)', data, re.S)
    print(json.loads(value.group(1)))
    pass

def main():
    print("第一页的新闻数据")
    url = "https://news.163.com/special/cm_yaowen20200213/"
    result = spider(url)
    handler_jsonp(result)
    time.sleep(2)
    for i in range(2, 6):
        print(f"第{i}页的新闻数据")
        url1 = f"https://news.163.com/special/cm_yaowen20200213_0{i}/"
        result1 = spider(url1)
        handler_jsonp(result1)
        time.sleep(2)
    pass

if __name__ == '__main__':
   main()
